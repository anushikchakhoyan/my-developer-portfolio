## Architecture Problem
When scaling multiple frontend brands across iGaming, E-commerce, and Admin tooling, traditional hex or HSL variables encounter non-uniform lightness and gamut clipping.

## Architectural Solution
We transitioned token pipelines to **OKLCH (Oklab Color Space)**:

- **Perceptual Uniformity**: Hue shifts do not degrade WCAG AA contrast.
- **Zero-Runtime Overhead**: Native CSS cascade layers (`@layer tokens, primitives, components`).
